# T425-SIM v2.15 — HAL RP2040

Esta versão conecta o núcleo genérico ao Raspberry Pi Pico por PIO e USB CDC.

A documentação oficial do Pico SDK confirma o uso de CMake, APIs de hardware, PIO, timers e USB; no RP2040 existem dois blocos PIO, cada um com quatro state machines. citeturn0search0turn0search3

## Links físicos

```text
LINK0: TX GP4 / RX GP5
LINK1: TX GP6 / RX GP7
```

Baud inicial: **115200 8N1**, deliberadamente conservador para o bring-up.

## Build

```bash
export PICO_SDK_PATH=/caminho/pico-sdk
cmake -S firmware_pico -B build -DT425_NODE_ID=0
cmake --build build -j
```

O fluxo segue o modelo oficial: `pico_sdk_import.cmake`, `pico_sdk_init()`, `pico_generate_pio_header()` e `pico_add_extra_outputs()`. citeturn0search2turn0search12

Para P01, P02 e P03 muda-se somente `T425_NODE_ID`.

**Importante:** nesta versão o ID ainda é parâmetro de compilação. Portanto o código-fonte é único, mas o UF2 é gerado separadamente para cada nó. A próxima etapa deverá gravar a configuração em Flash/NVM ou recebê-la pelo USB, permitindo um único UF2 para todos.
